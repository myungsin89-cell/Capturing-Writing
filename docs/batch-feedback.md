# 수업 중 묶음 피드백

주제 관리실은 **개인 피드백 / 묶음 피드백** 탭으로 나뉩니다. 기본은 개인 피드백이며, 탭을 바꿔도 작성 중인 조언과 묶음 작업의 선택·검토 상태가 유지됩니다.

1. 상단 **학생 링크·QR 안내** 옆의 **피드백 기준**을 눌러 수업 목표, 살펴볼 기준, 피드백 방식을 저장합니다. 독립 설정창에서 다른 주제에 저장한 기준도 불러와 수정할 수 있습니다.
2. **묶음 피드백** 탭에서 제출한 학생 중 이번에 확인할 학생을 선택하고 **폴더 준비**를 누릅니다. 그 시점의 제출본만 별도 Google Docs로 준비하며, 작성 중인 학생의 공책은 계속 열려 있습니다.
3. **기준 복사**를 누릅니다. Brisk의 Batch Feedback에서 준비한 폴더를 가져오고, 복사한 기준을 피드백 요청란에 붙여 넣습니다. Brisk에서 생성한 조언을 검토하고 각 문서에 삽입합니다.
4. 쓰담으로 돌아와 **묶음 첨삭 가져오기**를 누릅니다. 기존에 가져온 내용과 교사가 수정한 내용은 유지합니다. 일부 문서에 첨삭이 없거나 오류가 나면 해당 학생만 다시 가져옵니다.
5. 제출본과 조언을 나란히 읽고 필요하면 직접 보완합니다. **읽고 확인했습니다**에 체크한 후 한 명씩 보내거나, 확인한 학생들을 함께 전송합니다. 조언을 수정하면 확인 체크가 해제됩니다.

전송하면 해당 학생의 고쳐 쓰기가 열립니다. 학생이 제출을 회수하거나 새 수정본을 올렸다면 이전 제출본의 피드백 전송을 차단하고 최신 상태를 보여 줍니다. 전체 마감은 이 기능과 별개이며, 마감 중에는 학생이 다시 제출할 수 없습니다.

## 개인 첨삭에서도 같은 기준 사용하기

주제에 한 번 저장한 기준은 개인·묶음 첨삭에서 함께 사용합니다. **개인 피드백** 탭에서 학생을 선택한 뒤 오른쪽 독스 연동 패널의 **기준 복사**를 누르고 Brisk에 붙여 넣으세요. 학생을 바꿔도 현재 주제의 기준이 그대로 적용됩니다. 전체 요청문은 상단 **피드백 기준** 설정창에서 확인할 수 있습니다. 자동 복사가 차단되면 직접 선택·복사할 요청문만 펼쳐집니다. **학생 독스 열기**를 눌렀을 때의 기준 자동 복사도 유지됩니다.

기준 변경은 개인 피드백과 새로 준비하는 묶음에 적용됩니다. 이미 준비한 묶음은 당시 기준을 유지하며, 현재 주제 기준과 달라지면 안내를 표시합니다. 기준 설정창의 저장하지 않은 변경 내용을 닫으려 하면 확인 안내가 나옵니다.

## 저장과 복구

- 주제별 기준과 학생에게 전송한 피드백은 기존 학급 데이터와 함께 Google Sheets에 저장합니다.
- 묶음 작업 기록과 검토 중인 조언은 현재 브라우저의 저장소에 보관합니다. 같은 교사 계정·학급·주제로 돌아오면 이어갈 수 있습니다. 브라우저 데이터를 지우거나 다른 기기로 이동하면 작업 기록은 이어지지 않습니다.
- 준비한 폴더와 제출본 독스는 교사의 Drive에 남습니다. 교사의 기존 학생 독스는 이 묶음 작업에서 변경하지 않습니다.
- 문서 준비가 일부 실패하면 **준비 실패·중단 문서 다시 준비**로 이어갑니다. 이미 준비한 문서와 삽입한 첨삭은 유지합니다.
- 쓰담에 유료 AI API는 연결하지 않습니다. Brisk의 기능과 이용 한도는 교사의 Brisk 계정에 따릅니다.

## 검증

`npm test`로 제출본 식별, 주제 분리, 부분 실패 복구, 교사 검토 조건, 원격 회수 확인, 전송 응답 유실 복구를 확인합니다.

`scripts/verify-batch-feedback.cjs`는 임시 브라우저에서 Google 응답을 가로채어 UI 전체 흐름을 확인합니다. Playwright와 Chromium이 필요하며, `PLAYWRIGHT_MODULE`, `CHROME_EXECUTABLE_PATH`, `APP_URL`, `BATCH_FEEDBACK_QA_DIR` 환경 변수로 실행 환경을 지정할 수 있습니다. 실제 Google 계정이나 Brisk에 접근하는 테스트는 아닙니다.

전송 직전 원격 상태를 확인하지만, 현재 Google Sheets 직결 구조는 여러 기기의 동시 쓰기를 원자적으로 잠그지는 않습니다.
