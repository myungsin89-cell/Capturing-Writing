# 주제 안에서 친구 완성 글 감상하기

학생이 자신의 주제 공책에서 **친구 완성 글 보기**를 누르면 같은 반·같은 주제의 친구 작품을 제목과 이름으로 볼 수 있습니다. 글을 선택하면 기존 공책과 같은 글꼴·줄바꿈·빈 줄로 읽고 이전·다음 공책을 넘깁니다. **내 노트로 돌아가기**로 돌아와 작성하던 내용을 이어 씁니다. 전환 전에 기기 초안을 저장하며, 저장 실패 시 이동을 보류합니다.

학생 책장의 각 주제 카드에도 **친구 완성 글 보기**를 표시합니다. 공책 위 도구줄에는 **친구 완성 글 보기 / 선생님께 질문 / 처음 글과 비교하기** 버튼과 작은 상태 표시를 둡니다. 글쓰기 안내는 공책 안쪽 위에서 작은 글씨·좁은 여백으로 전체 내용을 보여 줍니다. 두 번째 제출본이 아직 없으면 비교 버튼을 비활성화하고 버튼 설명에 이유를 표시합니다.

최종 완성의 칭찬과 작품 감상·성장 비교 안내는 새 승인본을 처음 열었을 때 모달로 한 번 보여 줍니다. 이후에는 상단의 작은 **최종 완성** 표시를 눌러 다시 볼 수 있습니다. 확인 여부는 학생·학급·주제·승인 시점별로 현재 기기에 보관합니다. 개인 수정 저장으로는 승인 시점이 바뀌지 않으므로 축하 안내를 다시 띄우지 않습니다.

첨삭은 화면 오른쪽에 고정된 **첨삭 보기** 버튼으로 여닫습니다. 모든 화면에서 오른쪽 끝의 사이드바가 겹쳐 열리고, **첨삭 닫기**를 누르면 오른쪽으로 밀려 들어갑니다. 전환 중에도 공책의 폭과 위치·문단 줄바꿈은 유지합니다. 사이드바 제목과 닫기 버튼은 고정하고 내용만 따로 스크롤합니다. 넓은 화면에서는 공책을 계속 사용할 수 있고, 작은 화면에서는 화면 대부분을 차지하며 배경을 가립니다. 새 첨삭이 도착하면 이전에 닫았어도 자동으로 열고, 같은 첨삭을 닫은 선택은 유지합니다. **선생님께 질문**을 누르면 패널의 질문 입력란으로 이동합니다. 작은 화면의 패널은 키보드 초점을 내부에 유지하며 Escape·닫기·바깥 클릭으로 닫습니다. 동작 줄이기 설정에서는 슬라이드 전환을 생략합니다.

교사가 드래그해 단 부분 첨삭은 본문의 시작·끝 위치와 원문 지문을 함께 저장해 같은 단어가 반복되어도 한 구간만 칠합니다. 학생이 문장 조언을 누르면 해당 원문 차수를 열어 그 위치를 보여 줍니다. 원문이 달라졌거나 위치가 없는 이전 첨삭의 인용문이 여러 곳에 있으면 임의로 전부 강조하지 않습니다. 인용문과 조언 자체는 그대로 읽을 수 있습니다.

교사는 주제 책장의 **완성 글 모음 · ○편** 또는 주제 관리실 상단의 **완성 글 모음**에서 같은 공책 뷰어로 작품을 읽습니다. 교사 모음에는 학생 자신의 작품까지 모두 포함합니다. 주제 마감 여부와 관계없이 승인된 완성 글을 볼 수 있으며, 문집 PDF 내보내기와는 별도의 읽기 기능입니다.

교사가 최종 완성 처리할 때 제목과 본문을 별도 승인본(`completedWriting`)으로 저장합니다. 이후 학생이 혼자 수정하거나 새 첨삭을 요청해도 친구에게는 이전 승인본을 보여 줍니다. 교사가 다시 최종 완성 처리하면 새 승인본으로 바뀝니다. 기존 자료에 승인본 필드가 없으면 현재 `FINAL_COMPLETED` 글을 사용합니다. 교사 화면은 기존 완료 자료의 승인본을 주제별로 한 번 보관해 이전 중계기도 해당 필드를 유지하도록 합니다. 새 주제를 만들 때 승인본도 이전 주제로 옮기고 새 공책에서는 비웁니다.

학생용 조회 응답에는 번호·이름·제목·승인 본문·완성 시점만 담습니다. 첨삭·질문·독스 주소·초안 이력은 반환하지 않으며 친구 글은 읽기 전용입니다. 교사 미리보기에는 감상 전환 버튼을 표시하지 않습니다. GAS와 시트 직결 경로 모두 학생 세션과 학급·주제를 확인합니다. 이전 GAS 중계기에 새 조회 기능이 없으면 기존 번호·이름 인증을 이용한 시트 직결 조회로 전환합니다.

교사 화면의 **첨삭 보내고 수정 열기**는 본문이 있는 첨삭 요청 상태(첫 제출·수정본 제출)에서만 활성화합니다. 화면의 폼 처리와 앱의 상태 갱신에서도 같은 조건을 확인합니다. 완성 글은 학생이 스스로 **더 다듬기**를 사용할 수 있습니다.

`npm test`는 공개 범위와 승인본 보관, 주제 전환, GAS·직결 조회를 확인합니다. `scripts/verify-friend-notebooks.cjs`는 실제 계정 없이 응답을 가로챈 브라우저에서 버튼 상태, 주제 분리, 이전 GAS 호환, 초안 보존, 읽기 전용, 모바일 넘침을 검증합니다. Playwright 설치 경로는 `PLAYWRIGHT_MODULE`로 지정할 수 있습니다.
