# 학생 맞춤법 검사

- 공책 상단 `맞춤법 검사`를 누르면 첨삭 영역이 열리고, 선생님 첨삭 위에 결과 카드가 나타납니다.
- 결과는 원래 표현과 수정 제안만 표시합니다. 자동 교체나 전체 적용 기능은 없습니다.
- 항목을 누르면 현재 공책의 정확한 위치를 선택합니다. 중복 표현의 위치가 모호하면 선택하지 않습니다.
- 학생이 직접 입력하면 해당 표현은 `변경됨`으로 표시됩니다. 정답으로 판정하지 않으며 다시 검사할 수 있습니다.
- 입력 중에는 자동으로 외부 검사를 실행하지 않습니다. 결과와 검사 원문은 화면 메모리에만 두고 공책/학생이 바뀌면 비웁니다.
- 한 번에 제목(최대 50자)과 본문 합계 10,000자까지 검사합니다.

## 외부 연결

`POST /api/spellcheck`에 `{ title, text }`만 전달합니다. 이름·번호·학급·로그인 토큰·교사 첨삭 등 다른 필드는 거절합니다. 브라우저 요청에 쿠키를 포함하지 않으며 서버는 원문을 기록하거나 캐시하지 않습니다.

서버는 `hanspell@1.0.1`의 다음 검사 연결을 사용합니다. 글은 검사 서비스에 전송되므로 본문에 학생이 직접 적은 개인정보까지 자동으로 제거되는 것은 아닙니다. 제공자의 보관 정책이나 서비스 지속 여부를 쓰담이 보장하지 않습니다. 별도 AI API/키는 사용하지 않습니다.

서비스 연결 실패/시간 초과는 오류로 표시하며 `오류 없음`으로 처리하지 않습니다. 모든 맞춤법·띄어쓰기 오류를 탐지하거나 올바른 추천을 보장하지 않습니다.

Vercel의 `api/spellcheck.js` 함수로 배포합니다. 개발 시에는 Vite의 개발용 동일 경로가 연결됩니다. 정적 파일 서버만으로는 검사 API가 실행되지 않습니다. 함수 실행 시간은 60초 이내로 제한합니다. 기존 호스팅 함수의 사용량 한도는 적용됩니다.

동일 출처 요청, 입력 길이 제한, 실행 중인 함수 내 동시 검사 제한과 IP별 임시 요청 제한을 적용합니다. 학교의 같은 IP에서 학생 여러 명이 사용할 수 있도록 분당 80건을 허용합니다. 함수 인스턴스 사이에 공유되는 제한은 아니므로 외부 서비스의 전체 호출량을 강제 보장하는 장치는 아닙니다.

## 확인

- `npm test`: 입력/전송 범위, 문단·위치 보존, 중복 표현, 직접 수정 이후 위치 이동, 외부 검사 실패.
- `node scripts/verify-spellcheck.cjs`: 임시 브라우저와 가상 검사 응답으로 학생 화면 확인. 실제 학생 정보나 실사용 글은 전송하지 않습니다.
