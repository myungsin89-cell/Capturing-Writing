# 학생 초안 자동 보관과 이전 글 복구

학생의 미제출 제목·본문은 Google Sheets가 아닌 **현재 기기의 브라우저**에 보관합니다. 학교 시트, 학급, 학생 식별정보·번호·이름, 주제를 구분합니다.

## 학생 사용 방법

- 입력할 때마다 즉시 보관합니다. 책장 이동, 새로고침, 다른 사이트 이동 뒤 같은 학생·주제 공책을 열면 이어서 쓸 수 있습니다.
- 저장에 성공했을 때만 **기기에 저장됨** 표시가 나옵니다.
- 공책 위쪽의 **이전 글 복구**를 누르면 보관 시각·제목·글자 수·본문 일부를 보고 선택할 수 있습니다. 미리보기를 읽고 **선택한 글로 복구**를 누릅니다.
- 복구 전 글도 이력에 보관하므로 다시 선택해 돌아갈 수 있습니다. 제출·복구·화면 이동, 일정 시간 간격, 큰 삭제·교체 시점을 중심으로 최근 이력 최대 12개를 보관합니다. 모든 타이핑 단계의 무제한 이력은 아닙니다.
- 제목·본문을 전부 지운 빈 상태도 최신 초안으로 저장합니다. 삭제 전 내용은 복구 이력에서 찾습니다.
- 제출한 글이 다른 기기 등에서 바뀌면 이전 초안을 무조건 덮어 불러오지 않습니다. **이전 글 복구**에서 내용을 확인합니다.
- 제출을 기다리는 동안에는 편집을 잠깐 막습니다. 성공하면 해당 제출 초안만 정리하고 이력은 남기며, 실패하면 초안을 유지합니다. 읽기 전용 공책의 복구는 제출 회수나 교사의 고쳐 쓰기 허용 뒤 가능합니다.

## 저장 실패와 다른 창

저장 공간 부족 등으로 실패하면 성공 표시를 없애고 경고합니다. **지금 글 복사**, **글 파일로 보관**, **저장 다시 시도**를 제공합니다. 저장 실패 상태에서는 공책에서 책장으로 바로 이동하지 않으며, 페이지 종료 시 브라우저 경고도 요청합니다.

다른 탭에서 같은 공책을 수정한 것이 확인되면 자동으로 덮어쓰지 않고 알립니다. 한 창에서 작업하고 필요한 글을 복사해 보관하세요. 복구를 명시적으로 선택하면 화면에만 남아 있던 글과 다른 창의 글도 함께 이력에 보관합니다. 브라우저의 저장소 자체를 여러 창에 걸쳐 원자적으로 잠그는 방식은 아닙니다.

## 기존 초안

예전 저장 키에는 작성자 정보가 없으므로 새 저장 공간에 자동으로 합치지 않습니다. 원본은 삭제하지 않고, **이전 글 복구 → 예전에 임시 보관한 글 확인**에서 작성한 본인의 글인지 확인한 후 미리보기·복구할 수 있습니다. 공용 기기라면 교사와 함께 확인하도록 안내합니다.

## 보관 범위

같은 기기·브라우저·사이트 주소에서 이용하는 보관 기능입니다. 다른 기기로 자동 이동하지 않으며, 브라우저 데이터 삭제·시크릿 창 종료·기기 고장까지 보호하는 외부 백업은 아닙니다. 실제 수업의 중요한 글은 제출하거나 별도 파일로 보관하세요.

교사 미리보기는 학생 초안을 읽거나 수정하는 저장 경로를 사용하지 않습니다.

## 검증

- `npm test`: 저장 공간 분리, 빈 글 저장, 복구 이력, 저장 충돌, 제출 후 정리, 기존 자료 보존.
- `scripts/verify-student-drafts.cjs`: 임시 브라우저와 모의 학생 API로 이동 직후 복원, 실제 복구 버튼, 저장 실패·복사·다운로드·재시도, 여러 탭, 기존 초안, 완성 후 이어 쓰기를 확인합니다. `PLAYWRIGHT_MODULE`, `CHROME_EXECUTABLE_PATH`, `APP_URL`, `STUDENT_DRAFT_QA_DIR`로 검증 환경을 지정합니다.
