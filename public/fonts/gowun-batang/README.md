GowunBatang-Regular.ttf is distributed with the SIL Open Font License in OFL.txt.
Source: https://github.com/google/fonts/tree/main/ofl/gowunbatang
Copyright 2021 The Gowun Batang Project Authors.

The booklet generator fetches this font only when creating a PDF and embeds the
original font tables. Font subsetting produced missing printed Hangul glyphs
despite correct Unicode text extraction, so it is deliberately disabled.
